# AI-Powered Resume Analyzer & Job Recommendation System

An AI-powered Python application that analyzes resumes,
extracts skills, evaluates resume quality, recommends
suitable jobs, identifies skill gaps and generates a
personalized learning plan.

## Features

- PDF resume parsing
- Resume section detection
- Automatic skill extraction
- Resume quality scoring
- Job recommendation
- Skill matching
- Semantic similarity
- Skill gap analysis
- Learning recommendations
- SQLite analysis history
- Streamlit dashboard
- Automated tests

## Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- PyMuPDF
- Scikit-learn
- Sentence Transformers
- Plotly
- SQLite
- Pytest
